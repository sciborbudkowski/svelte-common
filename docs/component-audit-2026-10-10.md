# svelte-common audit — 2026-10-10

Subsequent implementation is recorded in [audit fix status](component-audit-fixes-2026-10-10.md).
This document preserves the findings and verification results from the original audit.

Audited the current working tree of version `1.1.4+1`, based on commit `6b168a3`, including the earlier modal and WebSocket fixes and the newly exported, untracked `CollapsibleTabBar`. Reviewed all 17 exported components, their supporting stores and services, utilities, shared styles, package metadata, and existing tests.

The findings below contain **43 actionable items: 2 P1, 34 P2, and 7 P3**. Two items concern release tooling rather than component implementation. Some findings depend on particular supported inputs or application configurations; those conditions are stated explicitly.

P1 means address before release or affected production use. P2 means a functional, accessibility, or reliability issue to fix next. P3 means a lower-impact defect or an API contract/lifecycle improvement. “Reproduced” means a local DOM/mock reproduction, not a real-browser result. “Inspected” means supported by source inspection, with standards checked where relevant.

No production fixes were applied during this audit. Existing working-tree changes were preserved. Temporary audit fixtures were removed from the repository after verification; copies remain in `/tmp/svelte-common-audit-2026-10-10/` for reference.

**Additional contracts worth deciding before implementation**

- CollapsibleCard wraps `visibleContent` in a button when `isVisibleContentClickable` is true. Interactive snippet contents can create nested buttons/links. Document a noninteractive snippet contract or redesign that trigger so composition remains valid.
- CircularTimer treats a nonpositive/nonfinite duration as complete without invoking `onTimeout`. Decide whether zero means immediate completion, disabled timing, or invalid input, and document that choice.
- Spinner and standalone CircularTimer do not expose an accessible label/status API. Decide whether they are decorative by default or convey application state; avoid announcing a timer every animation frame.
- WebSocket reconnect settings accept arbitrary numbers. Normalize finite nonnegative delays and integer attempt limits. Also document whether `init()` changing token/UUID must replace an already open connection; currently it only changes credentials for a later connection.
- Offline replay is an application-owned contract: persisted actions contain a relative endpoint and explicit headers/body, but do not carry the ApiClient's base URL or default credentials. Namespace adapters by client/user or add replay context. Require server-side idempotency when automatic replay of a possibly committed mutation could duplicate an operation.

Start with F01–F02, then modal/carousel/background accessibility and the broken FloatingButton/CollapsibleTabBar behavior. Next address callback/timer ownership, GPS and download recovery. Finish with release-tool compatibility and formatting. Add focused regression tests for each fix; the current passing suite did not cover the reproduced cases.

The audit used source inspection, jsdom, fake timers, mocked observers/network/browser APIs, SSR rendering and local build checks. Svelte transitions were disabled in the temporary DOM harness because jsdom does not implement the required Web Animations behavior. No Chromium or Playwright installation was available. Layout, pointer capture, actual keyboard traversal, screen-reader announcements, mobile save/share behavior and reduced-motion animation should therefore be verified in real browsers after fixes. This audit identifies observed and source-supported problems; it cannot guarantee that every possible issue has been found.
